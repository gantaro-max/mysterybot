## 1. アカウント登録とログイン

### 初回登録

1. ブラウザで `/auth/register` にアクセス
2. 以下を入力して「登録する」をクリック：
   - **イベントID**（例: `wedding2024`）— 英数字・ハイフンのみ、参加者が「開始」コマンドで使うID
   - **イベント名**（例: `田中家 結婚式`）— 管理画面に表示される名前
   - **パスワード** — ログイン用パスワード

> **注意**: イベントIDは後から変更できません。短くて覚えやすいものを推奨します。

### ログイン

1. `/auth/login` にアクセス
2. イベントIDとパスワードを入力

## 2. ダッシュボードの見方

ログイン後に表示されるダッシュボードには以下の情報があります：

| セクション | 内容 |
|:--|:--|
| イベント進行管理 | 現在の状態（準備中 / 開催中）と開始ボタン |
| 参加用QRコード | 参加者に配布するQRコード |
| シナリオ編集 | 問題の追加・編集画面へのリンク |
| ランキング | クリアタイム順位表へのリンク |

### イベントの状態

- **準備中**（オレンジ）: 参加者がLINEで話しかけても「準備中」と返信されます。リハーサルは可能です。
- **開催中**（グリーン）: 参加者が自由にゲームに参加できます。開始から24時間後に自動終了します。

## 3. シナリオ（問題）の作成

### 問題の追加

1. ダッシュボードから「シナリオ編集」をクリック
2. 「問題を追加する」セクションに入力：

| 項目 | 説明 | 必須 |
|:--|:--|:--|
| 問題文 | プレイヤーに表示される謎の説明文 | 必須 |
| 正解 | 正解のキーワード。カンマ区切りで複数登録可（例: `答え,こたえ,KOTAE`） | 必須 |
| ヒント | 「ヒント」コマンド時に表示するメッセージ | 任意 |
| 正解時メッセージ | 正解した時に表示するメッセージ | 任意 |
| 画像 | 問題に添付する画像（JPEG/PNG/GIF、最大10MB） | 任意 |

> **正解のTips**: 大文字小文字・全角半角は自動的に正規化されます。「答え,こたえ」のように複数登録すると正解の揺れに対応できます。

### 問題の順番変更・編集・削除

シナリオ一覧画面（`/user/riddles`）で各問題の「編集」「削除」ボタンが使えます。

### 出題モードの設定

シナリオ一覧画面の「設定」から変更できます：

| モード | 説明 |
|:--|:--|
| 順番出題（デフォルト） | Stage No. 順に出題 |
| ランダム出題 | プレイヤーごとにランダムな順序で出題 |

## 4. カタログからのインポート

管理者があらかじめ用意した良質な問題を、そのまま自分のイベントに取り込むことができます。

1. シナリオ一覧画面の「カタログから選ぶ」をクリック
2. カテゴリ別に問題一覧が表示される
3. 取り込みたい問題の「このイベントに追加」をクリック

> インポートした問題は自分のシナリオとして自由に編集できます。

---

## 5. イベントの本番開始

1. ダッシュボードの「イベントを本番開始する」ボタンをクリック
2. 確認ダイアログで「OK」を選択

**開始後の注意点:**
- 開始した瞬間から**24時間のカウントダウン**が始まります
- 24時間後は参加者の回答が自動的に締め切られます
- 一度開始すると、管理者によるリセット以外では開始時刻は変更できません

> **リハーサルをしたい場合**: 本番開始前（「準備中」の状態）であれば、LINEで「開始 イベントID」と送信してゲームをテストできます。「リセット」コマンドで参加者データをリセットできます。

## 6. 参加者の案内方法

### QRコードの配布

ダッシュボードに表示される QR コードを会場のスクリーンや印刷物に掲載してください。
このQRコードはLINE公式アカウントの友だち追加用です。

### 参加手順（参加者に伝える内容）

1. QRコードを読み込んで「追加」または「トーク」をタップ
2. トーク画面で以下を送信：
   ```
   開始 イベントID
   ```
   （例: `開始 wedding2024`）
3. チーム名を入力してゲームスタート

### LINE Bot のコマンド一覧（参加者向け）

| コマンド | 動作 |
|:--|:--|
| `開始 イベントID` | ゲーム参加・再開 |
| `ヒント` | 現在の問題のヒントを表示 |
| `遊び方` / `ヘルプ` | 操作ガイドを表示 |
| `リセット` | 自分のプレイデータを削除（最初からやり直し） |

## 7. ランキングの確認

ダッシュボードの「ランキングを見る」から確認できます。

- クリアタイム順でランキング表示（早くクリアしたチームが上位）
- 未クリアのチームはランキング外（ページ下部に表示）
- **会場スクリーンへの表示に最適**: ランキングページはリアルタイムで更新されます

---

## 8. リセット方法

### 参加者が自分でリセット

プレイヤーが「リセット」と送信すると、そのプレイヤーのデータだけが削除されます。

### 管理者によるイベント全体のリセット

スーパー管理者（`/admin`）からイベントの「開始時間リセット」を実行すると、イベントが「準備中」の状態に戻ります（参加者データは残ります）。

## 9. よくある質問

**Q. 参加者が「開始」を送っても反応がない**
- イベントが「本番開始」されているか確認してください（「準備中」だと「準備中です」と返答されます）
- イベントIDが正しいか確認してください（大文字小文字は区別されます）

**Q. 画像が表示されない**
- 画像ファイルのサイズが10MB以下か確認してください
- JPEG / PNG / GIF 形式のみ対応しています

**Q. 正解を送っても正解にならない**
- 正解に登録されているキーワードを再確認してください（シナリオ編集画面の「編集」から確認可能）
- カンマ区切りで複数の正解パターンを登録すると揺れに対応できます

**Q. 24時間以内にイベントが終わりそうにない**
- スーパー管理者に「開始時間リセット」を依頼し、イベントを「準備中」に戻してもらってください
- 準備中の状態では時間制限はありません

**Q. テスト中に作ったプレイヤーデータを消したい**
- LINEで「リセット」と送信するか、スーパー管理者に依頼してください
